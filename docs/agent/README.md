# Пакет для агента-исполнителя

Порядок чтения: `SPEC.md` → `ARCHITECTURE.md` → одна задача из `tasks/`.

Правила работы:
- Выполняй **ровно одну** задачу за сессию, по порядку `T01 → T09`. Номер задачи передаётся в промпте.
- Читай только файлы из раздела «Контекст» задачи. Остальной код не сканируй.
- Не выходи за «Границы» задачи; найденное вне scope запиши в `docs/agent/NOTES.md`.
- Задача завершена, только когда выполнены все «Критерии готовности» (DoD) и прошли команды проверки.
- В конце отметь задачу `[x]` в `PLAN.md` и сделай один коммит `T0N: <кратко>`.

Шаблон промпта для запуска:
> Прочитай docs/agent/README.md, docs/agent/SPEC.md, docs/agent/ARCHITECTURE.md и docs/agent/tasks/T0N-*.md. Выполни задачу T0N строго в её границах.
