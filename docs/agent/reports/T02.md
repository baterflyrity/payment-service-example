# T02. Доменный слой (F3)

## Статус
Выполнено

## Что сделано
- `src/payment_service/domain/payment.py` — `PaymentStatus` (StrEnum: pending/succeeded/failed), `Currency` (StrEnum: RUB/USD/EUR), `Payment` (slots-dataclass) с фабрикой `Payment.create(...)`:
  - нормализует `amount` через `Decimal(...).quantize(0.01)`, отклоняет `<= 0` и `NaN`/`Infinity` (`ValueError`);
  - приводит `currency` к `Currency`, копирует `metadata`, генерирует `id` и `created_at` (UTC по умолчанию);
  - сразу регистрирует доменное событие `PaymentCreated`;
  - `mark_succeeded(now)` / `mark_failed(now)` — только из `pending`, иначе `InvalidStatusTransition`; выставляют `processed_at`;
  - `is_final`, `ensure_same_request(request_hash)` (иначе `IdempotencyConflict`), `pull_events()` (отдаёт и очищает накопленные события).
- `src/payment_service/domain/events.py` — `PaymentCreated(event_id, payment_id, occurred_at)` (frozen) с `event_type == "payment.created"`; `OutboxMessage(id, event_id, event_type, payload, attempts)` для типизированной выдачи `lock_unpublished`.
- `src/payment_service/domain/errors.py` — `DomainError` и наследники `PaymentNotFound`, `IdempotencyConflict`, `DuplicateIdempotencyKey`, `InvalidStatusTransition` (с полезными атрибутами: `payment_id`, `idempotency_key`, `current`, `target`).
- `src/payment_service/domain/ports.py` — `Protocol`-порты: `PaymentRepository` (`add`, `get`, `get_by_idempotency_key`, `get_for_update`), `OutboxRepository` (`add`, `lock_unpublished`, `mark_published`, `mark_failed`), `UnitOfWork` (async CM + `payments`/`outbox`/`commit`/`rollback`), `PaymentGateway` (`process(payment_id, amount, currency) -> bool`), `WebhookSender` (`send(webhook_url, payload)`), `EventPublisher` (`publish(event)`).
- `src/payment_service/domain/__init__.py` — публичный экспорт доменных сущностей, событий, ошибок и портов.
- `tests/unit/domain/test_payment.py` — 29 тестов: создание и поля, квантование/валидация amount, валюты, копирование metadata, переходы статусов (включая запрещённые), сверка idempotency, регистрация и дренаж событий, `PaymentNotFound`.

## Для следующей задачи
- Домен импортируется как `payment_service.domain` (или из подмодулей); внешних зависимостей нет, `domain/__init__.py` реэкспортирует всё нужное.
- `PaymentRepository.add` отвечает и за вставку нового платежа, и за сохранение изменений существующего (отдельного `update` в порте нет) — T03/T06 должны это учесть.
- `OutboxRepository.lock_unpublished(limit) -> Sequence[OutboxMessage]`, `mark_published(ids: Sequence[int])`, `mark_failed(id: int, error: str)`; `OutboxMessage` содержит `id`, `event_id`, `event_type`, `payload`, `attempts`.
- `PaymentGateway.process(payment_id, amount, currency) -> bool` — эмулятор шлюза в T06 может адаптировать сигнатуру под этот порт.
- `Payment.create` требует keyword-only аргументов; `now` по умолчанию `datetime.now(UTC)`. События забираются ровно один раз через `pull_events()`.
- `alembic/env.py` всё ещё указывает на `payment_service.models.Base.metadata` — T03 должен переключить на `infrastructure/db` ORM.
