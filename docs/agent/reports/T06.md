## Что сделано
- `src/payment_service/infrastructure/gateway.py` — `RandomPaymentGateway`: задержка 2–5 с, 90% succeeded; задержки, `success_rate`, `sleep` и `rng` настраиваются (для тестов); данные платежа шлюзом не используются.
- `src/payment_service/infrastructure/webhook.py` — `HttpxWebhookSender`: POST через переданный `httpx.AsyncClient`, таймаут 10 с, не-2xx → `response.raise_for_status()`.
- `src/payment_service/application/process_payment.py` — `ProcessPaymentService`:
  - UoW #1: `get_for_update`, отсутствие платежа → `PaymentNotFound`;
  - шлюз вызывается только для `pending`, вне транзакции с блокировкой;
  - UoW #2: повторный `get_for_update`, повторная проверка «уже финальный» (конкурентный consumer не перезаписывается), `mark_succeeded`/`mark_failed` + `add` + `commit`;
  - webhook отправляется после фиксации статуса; его ошибка пробрасывается наружу для retry;
  - payload плоский: `event_id, payment_id, status, amount, currency, processed_at`.
- `src/payment_service/infrastructure/messaging/topology.py` — exchanges `payments`, `payments.retry`, `payments.dlx` (direct, durable); очереди `payments.new`, `payments.retry.1` (TTL 2 000 мс), `payments.retry.2` (TTL 4 000 мс) с DLX → exchange `payments` / routing key `payments.new`, `payments.dlq`; `declare_topology(broker)` для идемпотентного объявления и привязок.
- `src/payment_service/entrypoints/consumer.py` — FastStream consumer:
  - подписка на `payments.new` через exchange `payments`, `AckPolicy.MANUAL`, prefetch 1, publisher confirms;
  - `parse_event` восстанавливает доменный `PaymentCreated`;
  - номер попытки из заголовка `x-attempt` (1-based, клампится в 1..3);
  - `schedule_retry_or_dead_letter`: попытки 1 и 2 → `payments.retry`/`payments.retry.N` с `x-attempt+1` и `x-last-error`; попытка 3 → `payments.dlx`/`payments.dlq` с `x-last-error`;
  - `process_delivery` подтверждает оригинал после публикации retry/DLQ; ошибка публикации не подтверждает оригинал;
  - startup собирает `ProcessPaymentService` (UoW, шлюз, webhook-отправитель) и объявляет топологию, shutdown закрывает HTTP-клиент.
- `src/payment_service/infrastructure/messaging/publisher.py`, `src/payment_service/entrypoints/outbox_relay.py` — импорты переведены на новую topology.
- Удалены заменённые модули: `payment_service/messaging/`, `payment_service/services/`, `payment_service/workers/`, `payment_service/schemas/` и их тесты `tests/test_consumer_retries.py`, `tests/test_payment_processor.py`.
- `docker-compose.yml` — команда consumer: `payment_service.entrypoints.consumer:app`.
