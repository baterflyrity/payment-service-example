## Что сделано
- `src/payment_service/application/commands.py` — `CreatePaymentCommand` (frozen dataclass): amount, currency, description, webhook_url, idempotency_key, metadata. Не зависит от Pydantic.
- `src/payment_service/application/idempotency.py` — `calculate_request_hash(command)` перенесён со старого `services/idempotency.py`; канонизация та же (amount quantize 0.01, sort_keys, компактный JSON).
- `src/payment_service/application/create_payment.py` — `CreatePaymentService(uow_factory, clock)`:
  - поиск по ключу в отдельном UoW; при наличии — `ensure_same_request` и `(existing, False)`;
  - иначе `Payment.create` + `outbox.add` для каждого `PaymentCreated` + `commit` в одном UoW, возвращает `(payment, True)`;
  - на `DuplicateIdempotencyKey` — перечитывание ключа в новом UoW и повторная сверка (гонка), `(existing, False)`.
- `src/payment_service/application/get_payment.py` — `GetPaymentService.execute`; отсутствие платежа → `PaymentNotFound`.
- `src/payment_service/container.py` — composition root: `make_unit_of_work()`, `utcnow()`, DI-провайдеры `get_unit_of_work_factory`, `get_create_payment_service`, `get_payment_service` (через `Depends`).
- `src/payment_service/entrypoints/api/`:
  - `schemas.py` — DTO `PaymentCreate` / `PaymentCreated` / `PaymentDetail`, перенесены из `schemas/payment.py`; добавлен валидатор JSON-безопасности `metadata` (NaN/Infinity → 422, как раньше);
  - `deps.py` — `require_api_key` перенесён из `api/dependencies.py`;
  - `errors.py` — глобальные handlers: `IdempotencyConflict → 409`, `PaymentNotFound → 404`, `DomainError → 422`;
  - `routers.py` — тонкие эндпоинты: DTO → `CreatePaymentCommand` → сервис → DTO; SQL/сессий нет;
  - `app.py` — сборка FastAPI (lifespan с outbox-паблишером перенесён без изменений), регистрация handlers и роутера.
- Удалены `src/payment_service/api/payments.py`, `api/dependencies.py`, `schemas/payment.py`, `services/idempotency.py`. `api/main.py` оставлен как шим, реэкспортирующий `app` (путь зафиксирован в Dockerfile/compose).
- Тесты:
  - `tests/unit/application/test_create_payment_service.py` — 4 unit-теста на in-memory fake UoW: новый платёж + 1 событие; повтор → тот же id и без нового события; другой body → `IdempotencyConflict`; гонка (`DuplicateIdempotencyKey` + «скрытый победитель») → существующий платёж, `created=False`, событий нет;
  - `tests/integration/test_create_payment.py` — 10 параллельных POST с одним `Idempotency-Key` на реальных соединениях БД → все 202, один `payment_id`, в БД 1 строка `payments` и 1 строка `outbox`;
  - `tests/conftest.py` — override `get_unit_of_work_factory` вместо `get_session` (UoW поверх тестового соединения со savepoint);
  - `tests/test_idempotency.py` переведён на `CreatePaymentCommand`; `tests/test_payment_schemas.py` — новый путь DTO + кейс NaN в metadata; в `tests/test_payments_api.py` ожидаемый `event_type` приведён к доменному `payment.created`.

## Проблемы и вне scope
- `schemas/` удалён не полностью: `schemas/events.py` нужен `workers/consumer.py` (T06). API-DTO вынесены в `entrypoints/api/schemas.py`; окончательное удаление/перенос `schemas/events.py` — в T06.
- `api/main.py` — временный шим для пути `payment_service.api.main:app` (Dockerfile и compose). Перенос точки входа — T05/T09.
- `OutboxORM.event_type` теперь `payment.created` (значение доменного события из T02), раньше старый роутер писал `payments.new`. Маршрутизация от него не зависит (в очередь `payments.new` публикуется payload); поправлено ожидание в API-тесте.
- См. `docs/agent/NOTES.md` (раздел T04).

## Для следующей задачи
- Сервисы: `application.create_payment.CreatePaymentService(uow_factory, clock)`, `application.get_payment.GetPaymentService(uow_factory)`; команда — `application.commands.CreatePaymentCommand`.
- Хеш запроса — `application.idempotency.calculate_request_hash(command)`; в домене поле называется `request_hash`.
- DI: `container.get_unit_of_work_factory()` возвращает `Callable[[], UnitOfWork]`; тесты/FastAPI подменяют именно её через `app.dependency_overrides`.
- Сборка приложения — `entrypoints.api.app.create_app()` / `app`; `api/main.py` только реэкспортирует. Роутер — `entrypoints.api.routers.router`, handlers — `entrypoints.api.errors.register_exception_handlers`.
- UoW-фабрика должна создавать новый UoW на каждый вызов: сервис вызывает её 2–3 раза за запрос (поиск, вставка, повторное чтение при гонке).
