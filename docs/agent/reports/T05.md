# T05. Outbox relay через UoW как отдельный процесс (F2, F5)

## Статус
Выполнено

## Что сделано
- `src/payment_service/application/relay_outbox.py` — `RelayOutboxService(uow_factory, publisher, batch_size)`:
  - `run_once()` в одном UoW: `outbox.lock_unpublished(batch_size)` → публикация каждого события → `mark_published` для успешных, `mark_failed` (`attempts+1`, `last_error`) для упавших → `commit`;
  - возвращает число опубликованных; `batch_size < 1` → `ValueError`;
  - `message_to_event()` восстанавливает доменный `PaymentCreated` из payload outbox;
  - ошибка публикации не прерывает проход: остальные события партии обрабатываются, упавшее остаётся в outbox для следующего `run_once`.
- `src/payment_service/infrastructure/messaging/publisher.py` — `FastStreamEventPublisher(broker)`: публикует в exchange `payments`, routing key `payments.new`, `message_id=event_id`, `persist=True`, `mandatory=True`; payload в прежнем формате (`event_id`, `payment_id`, `occurred_at`). `broker.publish` ждёт publisher confirm (aiormq `publisher_confirms=True` по умолчанию).
- `src/payment_service/messaging/topology.py` — добавлены `PAYMENTS_EXCHANGE` (direct, durable) и `PAYMENTS_NEW_ROUTING_KEY`; существующие очереди не менялись (полная retry/DLQ-топология — T06).
- `src/payment_service/entrypoints/outbox_relay.py` — отдельный процесс: объявляет exchange и bind очереди `payments.new`, крутит `run_once()` с `OUTBOX_POLL_INTERVAL_SECONDS`, переподключается после ошибок, graceful shutdown по SIGTERM/SIGINT через `asyncio.Event`; запуск `python -m payment_service.entrypoints.outbox_relay`.
- `src/payment_service/entrypoints/api/app.py` — из lifespan убраны задача outbox-паблишера и создание брокера; осталось только `engine.dispose()`.
- `docker-compose.yml` — добавлен сервис `outbox-relay` (тот же образ, `DATABASE_URL`, `RABBITMQ_URL`, outbox-настройки; зависит от migrations/postgres/rabbitmq; `restart: unless-stopped`). У `api` убраны неиспользуемые `OUTBOX_*`.
- Удалён `src/payment_service/workers/outbox_publisher.py` (прямой SQL в обход UoW) и заменённый `tests/test_outbox_publisher.py`.
- `tests/unit/application/test_relay_outbox_service.py` — 4 unit-теста на fake UoW/брокере: успех → published; ошибка брокера → не published, attempts+1, last_error, публикация со следующего `run_once`; ограничение batch_size; `ValueError` при `batch_size < 1`.
