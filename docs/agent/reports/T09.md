## Проблемы и вне scope
- `docker compose ps/logs/down` без `.env`/`API_KEY` по-прежнему падают из-за `${API_KEY:?...}`. Это осознанное поведение: README требует `cp .env.example .env`; дефолтный API key не добавлялся по соображениям безопасности.
- `ruff format --check` расходится с существующим кодом (pre-existing, форматирование не входило в DoD).
- Шим `src/payment_service/api/main.py` оставлен для обратной совместимости путей; команды compose/Dockerfile уже используют `entrypoints`.
